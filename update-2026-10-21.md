# GSP Coin Core v2.2.0 Release & Development Update (October 21, 2026)

Hey everyone,

I'm excited to share a major update for GSP Coin Core: **v2.2.0.0** is officially ready! 

Over the past few days, I did a deep-dive audit across the entire codebase, fixed the long-standing synchronization and fork issues that some community members experienced, hardened wallet startup resilience, and completely modernized our build pipelines so we now have official, automated release binaries for **Windows**, **macOS**, **Ubuntu 22.04**, and **Ubuntu 24.04**.

Here is a full breakdown of what changed, why it matters, and how to upgrade your wallets and nodes.

---

## What We Fixed & Upgraded

### 1. Chain Synchronization & Hard Checkpoints (No More Forking)
- **The Problem:** In earlier versions, our checkpoint list stopped at genesis. When peers advertised conflicting histories or when network nodes restarted after a split, some wallets ended up stuck on orphaned chains or stalled during initial sync.
- **The Fix:** I added hard, verified block checkpoints all the way up to **Block 498,000** in [`src/chainparams.cpp`](src/chainparams.cpp). Now, any attempt by rogue or desynced peers to push an invalid chain is immediately rejected.
- **Faster Sync:** Set `defaultAssumeValid` to Block 498,000 and updated `nMinimumChainWork`. New wallets and nodes syncing from scratch will validate canonical history significantly faster.

### 2. Live DNS Seeds & Reliable Static Peers
- **The Problem:** Several legacy seed nodes were offline, making first-time peer discovery slow or unreliable without manual `addnode` entries.
- **The Fix:** 
  - Added our active DNS seed servers (`explorer.gspcoin.us` and `explorer.globalsocialpost.com`).
  - Populated static fallback peers in [`src/chainparamsseeds.h`](src/chainparamsseeds.h) with verified, 24/7 seed nodes on port `27653` (`130.162.237.49`, `129.146.161.225`, `129.146.20.199`, `37.59.20.42`). You will connect and start syncing immediately upon launching the wallet.

### 3. Startup Crash Protection (Corrupt Cache Auto-Recovery)
- **The Problem:** If your computer suddenly shut down or lost power, flat database cache files like `sporks.dat`, `mncache.dat`, or `powcache.dat` could get corrupted. The wallet would halt with an `InitError` pop-up and refuse to start until you manually hunted down and deleted those files.
- **The Fix:** Updated [`src/init.cpp`](src/init.cpp) to handle corrupted cache files gracefully. If a corrupted file is detected, the wallet clears the damaged cache automatically, logs a warning, and rebuilds fresh state directly from the network without crashing.

### 4. Timestamp Underflow Fix
- Fixed an unsigned integer underflow bug where unconfirmed transactions (`-1`) were stored in an unsigned `uint32_t`, causing confirmation time calculation glitches. Converted these to signed 64-bit integers (`int64_t`) in [`src/wallet/wallet.cpp`](src/wallet/wallet.cpp) and [`src/consensus/tx_verify.cpp`](src/consensus/tx_verify.cpp).

### 5. Branding, Domains & Copyright Refresh
- Completely updated all hardcoded Bitroeum/Dash legacy URLs and text across the client.
- Website, explorers, and API endpoints are now unified to **`https://gspcoin.us`** and **`https://explorer.gspcoin.us`**.
- Updated copyright year to **2026** and version string to **`v2.2.0.0`** (Client Version `2020000`).
- Updated `README.md`, manpages, Debian control files, and Docker setups with official Discord and Telegram community links.

### 6. Modernized Multi-Platform Build System
Our GitHub Actions CI has been completely revamped and verified across all platforms:
- **Windows (64-bit MinGW):** Clean cross-compilation on Ubuntu 22.04 with GCC 12 MinGW. Resolved OpenSSL 1.1 PRNG deprecation warnings, fixed Windows static Qt platform plugin (`-lqwindows`) system library linking, and restored NSIS installer scripts.
- **Ubuntu 24.04 LTS:** Fully modernized for GCC 14! Fixed standard library `<cstdint>` and `<stdexcept>` inclusions, patched bitfield integer promotions for `TxInUndoSerializer`, and fixed Python 3.12 build script requirements.
- **Ubuntu 22.04 LTS:** Clean native builds using standard GCC 11 with BLS symbol conflict patches (`-Dbn_init=relic_bn_init`).
- **macOS Intel (macOS 15 Sequoia / Xcode 16):** Resolved Qt static Cocoa framework dependencies (`-framework Carbon -framework IOSurface -framework QuartzCore -framework CoreVideo -framework Metal`), patched legacy C++17 `unary_function` headers, eliminated upstream GMP download timeouts by bundling GMP 6.3.0 in the repo, and added automatic `.dmg` packaging via `make deploy`.

## How to Upgrade

### For Desktop Wallet Users (Windows & Mac)
1. Close your existing GSP Coin wallet completely (`File -> Exit`).
2. **Always make a backup of your `wallet.dat`** before upgrading:
   - **Windows:** `%APPDATA%\Gspcoin\wallet.dat`
   - **macOS:** `~/Library/Application Support/Gspcoin/wallet.dat`
3. Download the new version:
   - **Windows:** Unzip `gspcoin-win-2.2.0.zip` and run `gspcoin-qt.exe`.
   - **macOS:** Open `Gspcoin-Qt.dmg` and drag `Gspcoin-Qt` into your `Applications` folder.
4. Launch the wallet. It will automatically connect to our seed nodes and sync to the tip of the canonical chain.

### For Masternode / VPS Operators (Ubuntu Linux)
1. Stop the running daemon:
   ```bash
   gspcoin-cli stop
   ```
2. Download and extract the matching package for your Ubuntu version:
   ```bash
   # For Ubuntu 22.04:
   wget https://github.com/gamgsp/gspcoin/raw/master/release/ubuntu22/gspcoin-ubuntu22-2.2.0.tar.gz
   tar -xzf gspcoin-ubuntu22-2.2.0.tar.gz
   sudo cp gspcoin-build/gspcoind gspcoin-build/gspcoin-cli /usr/local/bin/

   # For Ubuntu 24.04:
   wget https://github.com/gamgsp/gspcoin/raw/master/release/ubuntu24/gspcoin-ubuntu24-2.2.0.tar.gz
   tar -xzf gspcoin-ubuntu24-2.2.0.tar.gz
   sudo cp gspcoin-build/gspcoind gspcoin-build/gspcoin-cli /usr/local/bin/
   ```
3. Restart `gspcoind`:
   ```bash
   gspcoind -daemon
   ```
4. Verify you are on the canonical chain:
   ```bash
   gspcoin-cli getblockcount
   gspcoin-cli getinfo
   ```
